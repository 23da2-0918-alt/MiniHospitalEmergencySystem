# Mini Hospital Emergency System

## Project Description

The Mini Hospital Emergency System is a Java-based application designed to manage patients and their emergency visits in a hospital environment.

## Main Features

* Patient registration and management
* Emergency patient queue management
* Patient search
* Visit management
* Visit history
* Add and remove patient visits
* Emergency priority handling

## Technologies Used

* Java
* Object-Oriented Programming
* Data Structures
* Git and GitHub

## How to Run

1. Open the project in an IDE such as IntelliJ IDEA, Eclipse, or VS Code.
2. Compile the Java source files.
3. Run the main Java program.
4. Follow the instructions displayed in the console.
